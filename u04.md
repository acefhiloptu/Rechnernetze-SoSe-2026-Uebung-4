# Aufgabe 2: CIDR

## a

103.161.122.83 => IP-Addresse  
/18 => Präfix-Länge

| Addresse (dezimal)	| Addresse (binär)						| Bedeutung 		|
| ---------------------	| -------------------------------------	| -----------------	|
| 103.161.122.83		| `01100111.10100001.01101010.01010011`	| IP-Adresse		|
| 255.255.192.0			| `11111111.11111111.11000000.00000000`	| Subnetzmaske		|
| 103.161.64.0			| `01100111.10100001.01000000.00000000`	| Netzwerkadresse	|
| 103.161.127.255		| `01100111.10100001.01111111.11111111`	| Broadcastadresse	|

Die Subnetzmaske ergibt sich aus dem Präfix. Diese gibt an, wieviele Bits (von links nach rechts) aus `1` gesetzt werden, auch genannt Netzwerk-Bits. Die restlichen Bits, auch gennant Host-Bits sind auf `0`. Um die Netzwerkadresse zu ermitteln, geht werden die Bits der IP-Adresse mit den Bits der Subnetmaske jeweils `AND` verknüfpt. Für die Broascastadresse werden die Bits der IP-Adresse, die bei der Subnetzmaske auf `0` stehen, auf `1` gestellt.
